## Sobre

Portfólio moderno e responsivo desenvolvido com HTML, CSS e JavaScript. O site apresenta minha trajetória como Analista de Testes QA e estudante de Engenharia de Software, com foco em qualidade de software, automação, APIs REST, front-end, mobile, metodologias ágeis e produto.

## Como Usar

Clone o repositório:

```bash
git clone https://github.com/Mariott0/nathanmariotto.git
```

Acesse a pasta do projeto:

```bash
cd nathanmariotto
```

Abra o arquivo `index.html` no navegador ou use um servidor local:

```bash
# Usando Python
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```
